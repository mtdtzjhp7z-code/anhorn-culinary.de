# anhorn-culinary.de

Website von Anhorn Culinary Consulting (Uwe Anhorn). Statischer OnePager, gehostet über GitHub Pages, Domain bei Strato.

## Aufbau
- `index.html` – Startseite (DE/EN umschaltbar)
- `impressum.html`, `datenschutz.html` – Rechtstexte (nur Deutsch)
- `assets/fonts/` – lokal gehostete Schriften (Bodoni Moda, Jost), keine Verbindung zu Google
- `assets/img/` – Bilder
- `CNAME` – eigene Domain für GitHub Pages

## Farben
- Dunkelgrün `#1F3D33`, Weiß `#FFFFFF`

## Kontaktformular
Versand über Web3Forms. Der Zugangsschlüssel steht in `index.html` als `WEB3FORMS_KEY`.

## Änderungen
Jede Änderung auf dem Branch `main` ist nach etwa einer Minute live.
